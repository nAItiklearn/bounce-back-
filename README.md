# Bounce Back

![Screenshot](screenshot.png)

Endless shooter platformer. Move, jump, shoot enemies, and loop through the map forever. ive also added the org headshots , go shooot them !!

## Run

```bash
python -m pip install -r requirements.txt
python main.py
```

## Controls

- A / D or arrows: move
- Space: jump
- Left mouse button: shoot
- Enter: play
- Esc: pause/resume
